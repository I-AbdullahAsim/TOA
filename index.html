Turing Drawings — Turmite Engine

2D Turmites (Langton-style walkers) produce reliable, beautiful emergent art.

Implementation Steps

  1. Choose a mode & palette
  2. Start the turmite — watch emergent pattern form
  3. Adjust steps per frame or max steps to refine
  4. Save PNG or add to gallery

System Architecture: Turmite Engine

The engine runs a single turmite (head) on a 2D grid. Each cell stores a small integer state. A rule set maps current cell state → (turn left/right/stay), write new state, and move forward. Repeated application of these local deterministic rules creates complex global patterns.

  • Grid: finite 2D array with wrap-around (toroidal)
  • Head: x,y position + direction (N,E,S,W)
  • Rule types: spiral, symmetric, maze, fractal, random
  • Palettes: curated + AI-guided generation
